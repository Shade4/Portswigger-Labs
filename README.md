# 🚀 PortSwigger Web Security Academy

> My journey through the PortSwigger Web Security Academy.

---

## 📖 About

This repository documents my progress through the **PortSwigger Web Security Academy Learning Path**.

Rather than organizing content solely by vulnerability type, this repository follows the official learning path provided by PortSwigger. Each folder contains notes, solved labs, payloads, methodologies, and key takeaways for the corresponding topic.

The goal of this repository is to build a well-organized knowledge base while improving my practical web application security skills.

---

## 🎯 Objectives

- Complete the entire PortSwigger Web Security Academy Learning Path.
- Solve every Apprentice, Practitioner, and Expert lab.
- Document concepts, methodologies, and exploitation techniques.
- Create concise notes for quick revision.
- Build a practical reference for future web application security assessments.
